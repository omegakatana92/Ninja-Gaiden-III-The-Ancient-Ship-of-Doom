# Ninja Gaiden III: The Ancient Ship of Doom — Native Recompilation

A fan-made native recompilation project for **Ninja Gaiden III: The Ancient Ship of Doom (NES)**, developed using [mstan's NESRecomp](https://github.com/mstan/nesrecomp) framework.

The goal is to bring the original NES game to modern Windows systems through native recompilation while preserving its original gameplay and behavior.

## Project Overview

This repository provides ROM-free source code, configuration files, and build infrastructure for the Ninja Gaiden III recompilation project.

### Features and Goals

- Native recompilation of NES game code.
- Windows build support using CMake.
- Preservation of the original NES gameplay experience.
- ROM-free source distribution.
- Support for user-supplied game ROMs.
- Continued development and compatibility improvements.

## Requirements

- Windows 10 or Windows 11
- CMake and a compatible C/C++ compiler
- NESRecomp framework and required dependencies
- A legally obtained copy of **Ninja Gaiden III: The Ancient Ship of Doom (USA)**

## Building the Project

Clone the repository:

```bash
git clone https://github.com/omegakatana92/Ninja-Gaiden-III-The-Ancient-Ship-of-Doom.git
```

Follow the repository's build configuration and NESRecomp instructions to generate the required game-specific code from your own ROM before compiling.

The repository includes PowerShell and shell build scripts for the project.
