# Ninja Gaiden III: The Ancient Ship of Doom — NES Recomp

A native Windows x64 recompilation project of **Ninja Gaiden III: The Ancient Ship of Doom (1991)** for the Nintendo Entertainment System, built using [mstan's NESRecomp framework](https://github.com/mstan/nesrecomp).

This project aims to bring the original NES experience to modern Windows PCs through static recompilation of the game's 6502 machine code into native executable code.

## Features

- Native Windows x64 executable
- NESRecomp-based static recompilation
- Original NES gameplay and mechanics
- Keyboard and controller support
- Windowed and fullscreen display
- ROM-selection launcher
- Original graphics, music, and sound effects sourced from the user's ROM

*Features are project targets and should be marked as verified only after successful testing.*

## Installation

1. Download the Windows x64 release ZIP.
2. Extract the archive into a folder.
3. Launch `NinjaGaidenIIIRecomp.exe`.
4. Select your legally obtained **Ninja Gaiden III: The Ancient Ship of Doom (USA)** NES ROM.
5. Start the game.

## ROM Requirements

This project does not provide or distribute copyrighted Nintendo or Tecmo game ROMs.

Users must supply their own legally obtained, compatible NES ROM.
